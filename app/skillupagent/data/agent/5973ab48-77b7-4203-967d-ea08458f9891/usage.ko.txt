## Agent Builder

대화를 통해 새 skillupagent 템플릿을 설계하고 생성해주는 에이전트입니다.

**수집하는 정보:**

| 항목 | 필수 | 설명 |
|------|------|------|
| name | 필수 | 에이전트 이름 (공백 없이) |
| desc | 필수 | 설명 (한 문장, 언어 무관) |
| require_ciw | 필수 | Cadence CIW 창 필요 여부 |
| system prompt | 필수 | 에이전트의 system.txt 내용 |
| usage guide | 선택 | 사용 안내 문서 (Markdown) |
| agent.py | 선택 | 플러그인 뼈대 코드 |

**사용 예시:**
```
레이어 속성을 조회하는 에이전트를 만들고 싶어.
이름은 query_layer로 하자.
설명은 "Virtuoso에서 레이어 속성을 조회합니다."
CIW 필요해.
system prompt는 ... (내용 입력)
... 확인 후 생성
```

"만들어봐" 또는 "yes"라고 하면 스테이징 경로에 파일들을 생성합니다.
이후 테스트를 거쳐 정식 에이전트 경로로 옮기면 됩니다.
