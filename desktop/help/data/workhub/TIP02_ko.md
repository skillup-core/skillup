# 히스토리와 Diff 비교

## 자동 히스토리 저장

편집 세션을 닫을 때(목록으로 복귀) 내용이 변경되었으면 스냅샷이 자동 저장됩니다. 최대 10개까지 보관됩니다.

## 히스토리 패널

편집 화면 헤더의 **[최신]** 버튼을 클릭하면 히스토리 목록이 열립니다.

| 버튼 | 동작 |
|------|------|
| **보기** | 해당 시점의 내용을 읽기 전용으로 표시 |
| **현재와 비교** | 선택한 스냅샷과 현재 내용을 diff로 비교 |
| **직전과 비교** | 스냅샷 간의 변경 내용을 diff로 비교 |
| **반영** | 해당 스냅샷 내용으로 현재 문서를 덮어씀 |

## Diff 모드

좌우 분할 화면으로 OLD / NEW를 나란히 비교합니다.

- 마크다운 본문: 변경된 단어에 **색상 테두리** 적용
- TODO / 체크리스트: 행 단위 배경색 비교
- **[diff 종료]** 버튼을 클릭하면 편집 모드로 복귀합니다
