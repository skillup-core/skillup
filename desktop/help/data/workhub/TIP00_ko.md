# 슬래시 명령과 검색 고급 기능

검색창에 `/`를 입력하면 사용 가능한 명령 목록이 표시됩니다.

## 슬래시 명령

| 명령 | 설명 |
|------|------|
| `/go 1234` | 문서 ID 1234로 바로 이동 |
| `/my` | 내가 작성한 문서만 표시 |
| `/history` | 내 작업 이력 다이얼로그 열기 |

## 태그 검색

- `#cadence` — cadence 태그가 붙은 문서만 표시
- `#cadence error` — cadence 태그 AND "error" 키워드 검색
- 태그를 여러 개 조합하면 AND 조건으로 교집합이 표시됩니다

목록의 태그 배지를 클릭하면 해당 태그가 검색창에 자동 입력됩니다.

## 검색 히스토리

↑ / ↓ 방향키로 이전 검색어를 불러올 수 있습니다. 최대 64개까지 저장되며 앱 재시작 후에도 유지됩니다.
