# 문서 연결과 인라인 링크

## 문서 연결 (연결 버튼)

편집 화면 헤더의 `[<]` 버튼을 눌러 **연결** 버튼을 펼칩니다. 연결 다이얼로그에서:

- 최근 문서 목록에서 클릭해 바로 연결
- 문서 ID를 직접 입력해 연결 추가
- 연결은 **양방향** — A→B 연결 시 B에서도 A가 연결 목록에 표시됨

## 인라인 문서 링크 (`[[`)

마크다운 편집 중 `[[`를 입력하면 문서 검색 팝업이 열립니다.

```
[[cadence 설정 메모]]
```

- 선택하면 `[[42|cadence 설정 메모]]` 형태로 삽입됩니다
- 미리보기 모드에서 배지 스타일로 렌더링되며 클릭 시 해당 문서로 이동
- 삭제된 문서 링크는 취소선으로 표시됩니다

## 인라인 멘션 (`@`)

`@`를 입력하면 팀원 목록에서 멘션을 삽입할 수 있습니다.

```
@[greenfish|김철수]
```
