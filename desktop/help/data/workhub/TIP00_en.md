# Slash Commands and Advanced Search

Type `/` in the search bar to see a list of available commands.

## Slash Commands

| Command | Description |
|---------|-------------|
| `/go 1234` | Jump directly to document ID 1234 |
| `/my` | Show only documents you own |
| `/history` | Open your action history dialog |

## Tag Search

- `#cadence` — show only documents tagged with *cadence*
- `#cadence error` — tag *cadence* AND keyword *error*
- Multiple tags are combined with AND (intersection)

Click a tag badge in the document list to auto-fill it in the search bar.

## Search History

Use ↑ / ↓ arrow keys to recall previous search terms. Up to 64 entries are saved and persist across app restarts.
