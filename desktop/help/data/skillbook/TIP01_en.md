## HASH TAGS — Categorize and Search

Add tags in the **HASH TAGS** section at the bottom of the function details view to organize and search for functions later.

**Adding Tags**  
Type a tag name in the HASH TAGS input field and press **Enter** or **comma (,)**.

**Searching by Tags**  
Click the search button (🔍) on the right side of the HASH TAGS area to open the tag search dialog.  
Select the desired tag to filter and show only functions with that tag.

**Usage Examples**
- `geometry` — Group geometry/coordinate-related functions
- `io` — Group file input/output functions
- `deprecated` — Mark deprecated functions
