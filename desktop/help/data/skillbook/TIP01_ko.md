## HASH TAGS — 카테고리 분류 및 검색

함수 상세 화면 하단의 **HASH TAGS** 영역에서 태그를 추가하면 나중에 태그로 묶어 검색할 수 있습니다.

**태그 추가**  
HASH TAGS 입력란에 태그 이름을 입력하고 **Enter** 또는 **쉼표(,)** 를 누릅니다.

**태그로 검색**  
HASH TAGS 영역 오른쪽의 검색 버튼(🔍)을 누르면 태그 검색 다이얼로그가 열립니다.  
원하는 태그를 선택하면 해당 태그가 붙은 함수 목록만 필터링됩니다.

**활용 예시**
- `geometry` — 도형/좌표 관련 함수 묶기
- `io` — 파일 입출력 관련 함수 묶기
- `deprecated` — 더 이상 사용하지 않는 함수 표시
