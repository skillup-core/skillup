## 키보드 단축키

| 단축키 | 동작 |
|---|---|
| **Ctrl+F5** | 코드 실행 (Run) |
| **F5** | 디버그 시작 / 계속 (Debug / Continue) |
| **F9** | 현재 줄 중단점 설정/해제 |
| **F10** | 다음 줄 실행 (Step Over) |
| **Shift+F5** | 디버그 세션 중지 |
| **Ctrl+/** | 현재 줄 또는 선택 영역 주석 처리/해제 |
| **Ctrl+S** | 현재 파일 저장 |
| **Alt+G** | 커서 위치의 심볼 선언으로 이동 |
| **Ctrl+클릭** | 클릭한 심볼의 선언으로 이동 |

## 출력 패널 레이아웃

**⊕** 버튼으로 출력 패널 위치를 **하단** ↔ **우측** 으로 전환합니다.  
화면이 넓을 때 우측 패널 배치를 쓰면 코드와 출력을 나란히 볼 수 있습니다.

출력 패널 헤더를 드래그하여 크기를 조절할 수 있습니다.
