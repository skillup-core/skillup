## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| **Ctrl+F5** | Run Code |
| **F5** | Start Debug / Continue |
| **F9** | Toggle Breakpoint on Current Line |
| **F10** | Step Over (Next Line) |
| **Shift+F5** | Stop Debug Session |
| **Ctrl+/** | Toggle Comment on Line or Selection |
| **Ctrl+S** | Save Current File |
| **Alt+G** | Go to Symbol Declaration at Cursor |
| **Ctrl+Click** | Go to Symbol Declaration |

## Output Panel Layout

Use the **⊕** button to switch the output panel position between **bottom** ↔ **right**.  
When your screen is wide, right panel layout lets you view code and output side by side.

Drag the output panel header to resize it.
