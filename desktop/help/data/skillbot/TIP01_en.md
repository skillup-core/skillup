## Group Files with Projects

When working with multiple SKILL files, using the **Projects** feature makes things much easier.

**Creating a Project**

1. Click the **☰** button on the left of the editor tab bar to open the project dialog.
2. Click **+ New Project**.
3. Enter a name and description, then use **+ Add Open Tabs** to add current editor tabs to the file list.
4. Click **Save**.

**Switching Projects**

When you switch to a different project, the editor automatically opens its files.  
Previously open tabs are saved, so switching back restores them exactly as they were.
