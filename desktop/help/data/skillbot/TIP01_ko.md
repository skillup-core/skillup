## 프로젝트로 파일 묶기

여러 SKILL 파일을 함께 작업할 때 **프로젝트** 기능을 활용하면 편리합니다.

**프로젝트 만들기**

1. 에디터 탭바 왼쪽의 **☰** 버튼을 클릭하여 프로젝트 다이얼로그를 엽니다.
2. **+ 새 프로젝트** 를 클릭합니다.
3. 이름과 설명을 입력한 뒤, **+ 열린 탭 추가** 로 현재 에디터의 탭을 파일 목록에 추가합니다.
4. **저장** 을 클릭합니다.

**프로젝트 전환**

다른 프로젝트로 전환하면 에디터가 해당 프로젝트의 파일들을 자동으로 엽니다.  
이전에 열어둔 탭은 저장되므로, 다시 전환하면 그대로 복원됩니다.
