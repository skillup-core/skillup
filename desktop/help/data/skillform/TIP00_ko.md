# 스킬 폼 시작하기

**스킬 폼**은 코드를 작성하지 않고 SKILL 자동화를 위한 인터랙티브 폼을 디자인할 수 있게 합니다. 시작하는 방법은 다음과 같습니다:

## 디자이너 워크플로우

1. **팔레트에서 컴포넌트를 드래그**하여 (텍스트, 체크박스, 드롭다운 등) 중앙 캔버스에 놓습니다.
2. **컴포넌트 모서리를 드래그**하여 크기를 조정하고 위치를 변경합니다. 그리드를 참고하여 정렬합니다.
3. **컴포넌트를 클릭**하여 오른쪽 패널에서 속성을 설정합니다.
4. **저장 버튼**으로 폼을 JSON 파일로 저장합니다.
5. **실행 버튼**을 클릭하여 폼 실행기로 전환하고 테스트합니다.

## 일반적인 컴포넌트 타입

- **텍스트** - 한 줄 텍스트 입력
- **숫자** - 유효성 검사가 있는 숫자 입력
- **체크박스** - 불린 토글 (여러 개 선택 가능)
- **라디오** - 상호 배타적 옵션
- **드롭다운** - 목록에서 선택
- **텍스트 영역** - 여러 줄 텍스트
- **날짜** - 날짜 선택기
- **파일 경로** - 파일 선택 다이얼로그
- **리스트/보드** - 행 테이블 (추가/편집/삭제 지원)
- **버튼** - 동작 버튼 (커스텀 로직 트리거)

## 팁

- **라벨** 컴포넌트를 제목이나 지침으로 사용합니다.
- **구분선**을 사용하여 섹션을 시각적으로 나눕니다.
- 속성에서 필수 필드를 설정하여 데이터 유효성 검사를 강제합니다.
- **리스트** 컴포넌트는 표 형식 데이터에 강력합니다—속성에서 열을 설정합니다.
- **코드** 버튼을 클릭하여 Shell, Python, SKILL 플랫폼의 실행 코드 예제를 봅니다.

## 결과 사용하기

사용자가 폼 실행기에서 폼을 제출하면 결과가 JSON으로 출력됩니다. 이 JSON을 복사하여 SKILL 자동화 스크립트에 사용하거나, 데이터베이스에 저장하거나, 다른 도구로 전달할 수 있습니다.
